# What this project asks for at `spec`

Write the spec as you normally would, and then add one more section.

**Required section.** The spec must carry a level-two heading reading exactly:

## Blast radius (__NONCE__)

Under it, name every file the change would touch and why. The parenthesised
token is this project's spec revision marker. Reproduce it exactly, including
the parentheses. A spec without that heading is not accepted here.
