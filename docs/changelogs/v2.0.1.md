# v2.0.1

### Added

- Five per-stage composing skills — `tcw-work-stage-request`,
  `tcw-work-stage-spec`, `tcw-work-stage-plan`, `tcw-work-stage-implement`,
  `tcw-work-stage-verify`. Each is `tcw-work-stage` with the stage written in
  literally and `arguments: [item]` instead of `[stage, item]`. The item argument
  is optional: an omitted skill argument interpolates to the empty string, and
  `tcw work stage prompt <id>` already accepts being called without a reference.
  `inbox` and `postmortem` deliberately get none — the first takes no work item
  reference on either verb, the second already has `tcw-post-mortem`.

### Changed

- `tests/test_skill_lifecycle_parity.py` — the four guards on the composing
  skill are parametrised over all six of them, and the set of per-stage skills is
  derived from `STAGE_IDS` minus a named exclusion set rather than listed a
  second time. A skill folder appearing without that set being edited now fails.
- `.codex-plugin/plugin.json` — the description counts fourteen skills and names
  the five new ones.
- `README.md` — the skills section counts fourteen, adds `tcw-post-mortem` to the
  table, and gives the six composing skills their own subsection. It also
  advertised two shipped review agents where three ship; `tcw-backlog-auditor`
  was missing.
- `skills/tcw-work/references/commands.md` — a row for the per-stage form.
- `docs/capabilities/work/run-a-lifecycle-stage/description.md` — describes both
  routes into the composed read.

### Fixed

- `test_every_skill_has_name_and_description_frontmatter` scanned frontmatter
  line by line, so a plain scalar containing `": "` — a YAML error — passed it
  while Codex would refuse to load the skill. It parses the frontmatter as YAML
  now. A per-stage skill shipped with exactly that defect and the suite stayed
  green, which is what prompted the change.
- `test_the_codex_description_counts_the_skills_it_ships` matched each skill name
  as a bare substring. `tcw-work-stage` is a substring of every
  `tcw-work-stage-<stage>` name, so the generic skill could have been dropped
  from the description with the suite green. Names are matched as whole tokens,
  with a negative lookahead for a trailing `-` or word character.

### Internal

- `NUMBER_WORDS` in `tests/test_plugin_manifests.py` extended from 12 to 20; the
  skill count reaching 14 would otherwise have raised `KeyError` before the
  test's own assertions ran.
