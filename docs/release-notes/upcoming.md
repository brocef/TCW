# Upcoming

User-facing release notes for the next version. Plain language — no jargon or
internal module names.

## Changed

- **Planning now asks you for reference material.** When TCW writes up a request,
  it asks what documentation, links, prior work, or files in the repo apply to the
  task, and records them alongside your request with a note on why each one
  matters. The next stage starts from your sources instead of going looking for
  them, so the material you already had open does not have to be found twice.
  Answering is optional — if you have nothing to point at, saying so is recorded
  too.
