## Improvements

- **A clear place for later changes to a work item's request.** When a decision
  or clarification arrives after an item is written up, the instructions now
  say where it goes: appended to the item's request (`initial-request.md`)
  under a dated heading, never to the raw `intake.md`. If the item already has
  a spec or plan, the change has to be carried into those too, since they are
  what the building and checking stages read. The instructions for filing new
  work no longer contradict this.
