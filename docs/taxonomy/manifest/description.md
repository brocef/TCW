A file in a project's `.tcw/` folder that says where other projects are on this machine: `.tcw/tcw-manifest.yaml`, committed and shared by everyone who checks the project out, and `.tcw/tcw-manifest.local.yaml`, kept out of version control for one person's machine. Each entry, under `projects:`, maps a project's ID to the path of its folder, relative to the project root (a personal entry may be absolute), and may give the repository the project is fetched from, written `<url>#<branch>`, with the `subfolder` of that repository the project sits in. A manifest records locations only: listing a project in one does not connect it, which only `projects:` in `.tcw/tcw-config.yaml` does. Like every file in `.tcw/`, a manifest starts with the `tcw-version` of its format. When no manifest places a project, TCW looks for its folder next to the project that names it and in the folders enclosing it.
