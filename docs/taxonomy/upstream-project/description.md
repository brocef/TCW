A connected project that a project reads from and never writes to, and which does not name that project back. A project declares it under `projects.upstream` in its `tcw-config.yaml`; the project and its whole family (parents, children and theirs) can read its taxonomy, capabilities and work items, and nothing writes into it from there. Only its own config is read — its connections are not followed. Elsewhere in the capabilities docs, "upstream" is also used loosely for whichever project an inherited entry comes from, which may be a writable parent or child; that looser use does not mean this relation.
