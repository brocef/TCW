A connected project a node reads from and never writes to, and which does not name that node back. A node declares it under connected-projects.upstream; the node and its whole family (parents, children and theirs) can read its taxonomy, capabilities and work items, and nothing writes into it from there. Only its own config is read — its connections are not followed. Elsewhere in the capabilities docs, "upstream" is also used loosely for whichever project an inherited entry comes from, which may be a writable parent or child; that looser use does not mean this relation.
