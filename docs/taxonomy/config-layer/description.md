One of the places TCW reads a project's configuration from, read in a fixed order: TCW's own defaults (built-in), the team's tcw-config.yaml, the person's user-wide file, the person's tcw-config.local.yaml beside the project's own file, and the environment overrides naming the project. Before the project's own layers come those of each parent whose link passes `config`, farthest first, of which only `work.tags` and `work.jira` are taken. A value in a later layer wins over the same value in an earlier one, and a person's layers may set only the keys TCW lists as personal.
