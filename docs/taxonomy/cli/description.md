The single `tcw` command surface: `validate` and `serve` at the top level, and the `taxonomy`, `capabilities`, `work` and `project` subcommand groups, all named as `tcw <noun> [<child noun>] <verb>` and all following one output contract — the command's product on standard output, narration and the name of every file written or removed on standard error, and one set of exit codes. The `project` group holds the commands about a project itself rather than its records, in six verbs: `tcw project new` makes a folder a TCW project or adds stores to it, `tcw project list` lists the projects it is connected to, `tcw project config` prints the configuration it runs with and, with `--origin`, where each value came from, `tcw project provision` fetches the stores it declares and the projects of its family that are not on this machine, `tcw project path` prints the folder a project is in on this machine, and `tcw project info` shows how the project is assembled. The TCW 3.x top-level commands that these verbs replace are not commands; typed, each is a usage error naming its replacement.
