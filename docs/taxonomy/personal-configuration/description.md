Configuration that belongs to one person rather than the team: a user-wide file and a `.tcw/tcw-config.local.yaml` kept out of version control, layered over the team's `.tcw/tcw-config.yaml`. The local file records its format version like every file in `.tcw/`; the user-wide file, shared by every TCW a person installs, does not. A person can add to or replace a stage's instructions, add commands that run after an item moves, change a procedure's text, name their own Jira credential variables, and say who they are, without changing what the rest of the team gets.
