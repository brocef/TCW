Pointing any of a project's three component stores — work, taxonomy,
capabilities — at a location other than its default `docs/<component>`
folder, through a `<component>.path` key in the project's `tcw-config.yaml`,
without changing the project's canonical ID or ownership. The location is a
path relative to the project or a `tcw://` folder address, and no two stores
may be the same folder or lie one inside the other.
