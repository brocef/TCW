**Before implementing, settle one open question.** TCW-115's handoff on this
ticket raises it. A parent's manifest is read before the project search. So,
once a parent has been fetched, a later command can find a project that is
already on this machine in a different folder than before.

The decision, made by the dispatching session under the user's instruction to
settle open questions: if an answer the search already found conflicts with a
parent manifest that arrived later, that is a graph problem. The message names
both folders, in the same shape as TCW-115 Design 7.4. The command never
switches folders silently. Write this into the spec as a dated decision, with a
criterion and a test, before or at the start of implement.
