# Say where a dated amendment to an item's request belongs

## Origin

GitHub issue [#74](https://github.com/brocef/TCW/issues/74), filed 2026-09-29 by @brocef.

> Where should a later, dated amendment to an item's original request go?
>
> The guidance says the arrival document, `intake.md`, is raw arrival and never edited. An item created with `inbox accept` has one. An older item had `initial-request.md` instead and no `intake.md`, and a decision made later needed recording against it. Nothing says whether to add a new file, append to the request, or put the amendment somewhere else, so the agent appended a dated section to `initial-request.md`.
>
> Seen on tcw 2.6.4.
>
> **Asked for:** a documented place for amendments that arrive after an item is written up. That could be an `amendments.md` or `notes.md` convention recognised by `tcw work show`, or a command such as `tcw work note <slug>` that appends a dated entry. Also a sentence in the work skill saying which file an agent should use.
