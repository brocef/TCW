As a user or agent, I ask the `commands-plan-work` skill to plan a work item, either one that already exists or one from a request I make in chat. The agent runs the request, spec and plan stages from wherever the item stands, reading each stage's instructions with `tcw work stage prompt <stage> <slug>`, writing what the stage asks for at the path `tcw work path` gives, and moving the item on with `tcw work advance` after request and after spec. It stops once the plan is written, before any code, without moving the item into implement, so I can review the plan. Where my project keeps the request in Jira, it stops after writing the request on the ticket, because a person moves a ticket out of request.

While writing up the request it asks me what reference material applies — documentation, links, prior work, files in the project — and records it with my request, so the stage that writes the spec starts from my sources instead of finding them again.
