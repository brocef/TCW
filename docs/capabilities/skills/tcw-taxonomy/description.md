As a user or agent, I open the `tcw-taxonomy` skill to learn how to keep my project's taxonomy through the `tcw taxonomy` command: declaring Vocabulary terms (the concepts the project reasons about) and Features (the areas where users or applications work with those concepts), linking related entries, and checking the result. It carries the judgment the command cannot: when a concept deserves its own entry, whether it is Vocabulary or a Feature, and where a Feature's description must stop so that behavior is described in capabilities instead.
Starting a taxonomy from an existing codebase is the `tcw-setup` skill, and declaring that a project inherits another project's taxonomy is the `tcw-configure` skill.
