As a user or agent, I open the `capabilities` skill to learn how to keep my project's capabilities ledger — the record of what a user can do — through the `tcw capabilities` command. It covers a work item that changes what users can do: checking the change against the capabilities already recorded, declaring the capabilities it adds, changes or deletes in the item's `capabilities.yaml`, linking each capability to a taxonomy Feature, and setting each capability's status as the work completes. It also covers getting the agreed wording for a capability from the parent project when several projects share one product.
Starting a ledger from an existing codebase is the `tcw-setup` skill, and declaring that a project inherits another project's capabilities is the `tcw-configure` skill.
