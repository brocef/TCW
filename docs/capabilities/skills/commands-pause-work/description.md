As a user or agent, I ask the `commands-pause-work` skill to stop the work in hand — because I am about to lose my connection, reboot, or pick the work up on another machine. The agent brings what it is doing to a coherent resting point rather than halting mid-edit, and asks whether I want the work in progress committed and pushed; if I do not answer, it commits and pushes anyway, since an absent user is the case that most needs the work to survive.
It then writes a `handoff-<UTC timestamp>.md` into each affected work item's folder, holding whatever context resuming needs — it decides what that is, having done the work; only the branch is required of it — so the work can be resumed from the board rather than from a conversation that may be gone. It runs no transition, so the item keeps its status and its claim. Then it reports where things stand and falls silent until I say to continue. Resuming reads that handoff and deletes it.
