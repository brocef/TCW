As a user or agent, I ask the `tcw-commands-verify-work` skill to verify a finished work item. The agent submits the item for review if it is still active, then assesses the work against the acceptance criteria in `spec.md` — reading the change, running the checks and forming an opinion, a part it may hand to a read-only subagent. It presents that assessment and stops for my decision rather than deciding for me.
When I accept, it writes `refined-outcome.md`. When I reject, it writes `rework.md` and sends the item back with `tcw work rework`. Before closeout it reconciles the capabilities ledger with what the item changed.
