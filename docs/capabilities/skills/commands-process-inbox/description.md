As a user or agent, I ask the `commands-process-inbox` skill to process my work inbox. The agent goes through every raw entry `tcw work inbox list` reports, decides whether each is one work item or several, chooses tags from my project's registered tags, and accepts it with `tcw work inbox accept`, which files the entry as the item's `intake.md`. It then runs the `request` stage over that intake to write `initial-request.md`, asking me whatever is unclear, and commits each item as it creates it. Where my project declares `work.tracker.inbox-query`, the tickets `inbox list` reports under `tracker tickets:` are worked the same way, except that the agent confirms with me before accepting one, because accepting a ticket claims it in the tracker.
It stops there. Carrying an item on into `spec` is the `commands-plan-work` skill.
