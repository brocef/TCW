As a user or agent, I ask the `commands-process-inbox` skill to decide on the arrivals in my work inbox. For each one, the agent reads the inbox stage's instructions with `tcw work stage prompt inbox`, then accepts the arrival by moving it on to request, splits it into several items, or turns it away with `tcw work discard` and a reason. Where my project keeps its work in Jira, the arrivals are the tickets `tcw work tickets list` reports, and accepting one is `tcw work tickets adopt <KEY>`.

For each accepted item it then runs the request stage, through `tcw work stage prompt request <slug>`, writing the request and asking me whatever is unclear. It stops there. Carrying an item on into spec is the `commands-plan-work` skill.
