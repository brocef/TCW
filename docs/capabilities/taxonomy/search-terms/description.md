As a user, I run `tcw taxonomy search <query>` to find entries whose name or description contains the text, ignoring case, across my project's own entries and the ones it inherits, each path once and matched on the combined entry. It prints one full identifier per line, or with `--json`, `{"schema": 2, "terms": [...]}`, each record carrying `overrides`, a full identifier or `null`. Where two parents that do not inherit from each other both have an entry at one path, a warning on standard error says which is used. No match prints nothing and exits 0. When a parent is not on this machine, it stops with exit 7.
