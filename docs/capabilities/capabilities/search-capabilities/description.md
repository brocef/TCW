As a user, I run `tcw capabilities search <query>` to find capabilities whose name or body contains the text, ignoring case, across my project's own capabilities and the ones it inherits, each path once and matched on the combined capability. It prints one full identifier per line, or with `--json`, `{"schema": 2, "capabilities": [...]}`, each record carrying `overrides`, a full identifier or `null`, and no `id`. Where two parents that do not inherit from each other both have a capability at one path, a warning on standard error says which is used. No match prints nothing and exits 0. When a parent is not on this machine, it stops with exit 7.
