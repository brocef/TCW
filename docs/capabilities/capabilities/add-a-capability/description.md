As a user, I run `tcw capabilities add <namespace/path> [name]` (with `-s <status>`, `--folder`, and a piped body) to scaffold a capability as a flat file or a promoted folder. The tool refuses a flat/folder collision. A write that Git refuses — a lock another process holds, a hook that says no — is rolled back too: whatever the command created is removed, and whatever was already there is left as it was.
