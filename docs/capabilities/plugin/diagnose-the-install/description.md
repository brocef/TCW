As a user, I run `/tcw-doctor` to check whether `tcw` is on PATH, how it was installed (pipx / editable / missing), and which version I have — and to install or refresh it when it is missing or behind. It tells me plainly when my CLI is older than the latest published one and how to move it forward, rather than assuming it should match my plugin version. It also tells me when an older install has left a leftover package sitting beside the current one, so I can clear it if I want to.
