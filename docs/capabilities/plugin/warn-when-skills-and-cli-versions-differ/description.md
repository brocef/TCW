As a user, when the `tcw` CLI on my PATH and the tcw plugin skills my agent loaded come from different releases, I am told so in the session: which version each one is, which one is behind, and the command that brings them into line — updating the plugin when the CLI is newer, upgrading the CLI when it is older. The warning never stops my work, and it says nothing when the two agree or when there is no `tcw` to ask. Under Claude it appears when the session starts; under Codex, and any other harness, every tcw skill asks the agent to run the same check once per session, so it depends on the agent doing so. Skills from a release older than this check cannot report anything.
