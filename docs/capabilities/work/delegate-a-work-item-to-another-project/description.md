As a user, I file work in another project from the one I am in with `tcw work new "<title>" --project <id>`. The other project must be one I can write into from here, and on this machine: a parent that lists my project among its children, a child I list, or a project reached from mine through such links alone. The item lands in that project's inbox, so its owners decide what to do with it; piped text becomes its request, and `--priority` is the only property I may set from here. The command prints the new item's full identifier, `<id>.work/<folder>`.

I can also mark an item there as blocked by one of mine: `tcw work edit <my-item> --blocks <id>.work/<folder>` adds my item to that item's `blocked-by`, and never creates anything.

When the other project keeps its items in Jira, `new --project` creates a ticket in that project's Jira inbox, with TCW Project set to its id. If the project is on this machine, has a work store with no uncommitted changes, and its workflow can move the ticket on, the ticket also becomes an item there: the command makes its folder, moves it to the request stage and prints its full identifier. Otherwise the ticket stays in the inbox, the command prints the ticket's key and exits 0, and stderr says why.

Both refuse (exit 3) and write nothing in the other project when it is not connected to mine, or is read-only from here: a parent that does not list my project among its children, a project reached only through such a parent, or a sibling, another child of one of my parents. They also refuse when it is not on this machine, whatever backend it uses. `edit --blocks`, and `new --project` into a filesystem-mode project, also refuse when it has no work store, or has uncommitted changes in its work store; that last check reads git without taking any lock in that repository. What delegation writes is left uncommitted in the other project's repository, and the command says which files, so that project's owners commit it.

The `TCW Item` a delegation sets in the other project is at most 255 characters: the title words are cut to the room the project ID and the key leave.
