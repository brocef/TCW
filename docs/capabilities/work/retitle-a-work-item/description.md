As a user, I run `tcw work edit <slug> --title "<new title>"` to change a work
item's title after creation. The item's folder name is not recomputed, so a
retitle never breaks an existing reference to the item; renaming the folder is
[Rename a work item](tcw://C/work/rename-a-work-item). The item's request
document is left alone — its heading is prose I edit myself.
