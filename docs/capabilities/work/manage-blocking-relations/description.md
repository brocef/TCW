As a user, I run `tcw work edit <item> --blocked-by <item>` to record that another work item blocks mine, `--unblocked-by <item>` to remove that. A blocker is recorded on the item it blocks, so to say that my item blocks another I run `--blocked-by` on that other item, from its own project; TCW 3.x's `--blocks` is removed. Each flag repeats. A blocker is always a work item, named by its folder name, its full identifier (`<project>.work/<folder>`) or its `tcw://` address, or, in a project that keeps its items in Jira, by its ticket key, bare or as `<project>.work/<KEY>`, and is kept in the item's `item.yaml` as its full identifier; an item cannot block itself. `tcw work show` lists what an item is blocked by and, worked out from the other items, what it blocks. `tcw validate` warns about a blocker that names no item, without failing.
