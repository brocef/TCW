As a user, I record coarse estimates with `tcw work new "<title>" --effort <level> --complexity <level>` or `tcw work edit <slug> --effort <level> --complexity <level>`, where `<level>` is one of `low | medium | high | very-high`. Both fields are optional and default to unset, and an empty value (`--effort ""`) clears one. `tcw work show` displays them when set (alongside priority); they do not appear in `tcw work list`. They are estimation signals only and do not affect ordering.
