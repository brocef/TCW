As a user, I run `tcw work new "<title>" --parent <slug>` to create a child work item under an existing item, so a large item can be broken into smaller ones that are each planned and worked on their own. `tcw work list` shows children indented under their parents. A child has its own status: it starts in `backlog` whatever state its parent is in, and keeps its parent through every one of its own transitions. A parent cannot be completed, discarded or dropped while anything beneath it is still open.
