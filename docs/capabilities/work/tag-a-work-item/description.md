As a user, I classify a work item with one or more **tags** drawn from a set my project registers centrally. I register the valid tags with `tcw work tags add <tag>…`, remove them with `tcw work tags rm <tag>…`, and see them with `tcw work tags list`, which prints one tag per line. Adding and removing maintain the registered set in `tcw-config.yaml` — changing only the `work.tags` lines and keeping my comments and formatting, or refusing with the exact edit to make by hand when the file cannot be edited that way. The file is named on standard error and left for me to commit, inside or outside a git repository; nothing is printed on standard output.

Only registered tags may be applied. I apply tags with `tcw work new "<title>" --tag <tag>` or `tcw work edit <slug> --tag <tag> --untag <tag>`, and applying a tag that is not registered is refused (exit 2). An item keeps a tag that was later removed from the registry until I untag it, and other edits to it still work. Tags are shown by `tcw work show`, and I filter the list to items carrying a tag with `tcw work list --tag <tag>`; given more than once, it lists items carrying **any** of the tags, and it combines with the other filters. Filtering on a tag that is not registered still filters, with a `warning:` line on standard error, so I can find items that still carry an old tag and clean them up. No match prints nothing and exits 0.

**Each `--tag` or `--untag` names one tag**; to give several I repeat the option, and a positional tag on `tags add` or `tags rm` is one tag per argument. A value containing a comma is refused as a usage error (exit 2) that tells me to repeat the option, rather than being split or quietly turned into one tag. A tag may only contain lowercase letters, digits and hyphens, and is read in that form wherever it is written: a `when: { tags: [...] }` condition in `tcw-config.yaml` treats `CLI` as `cli`.

Agent planning workflows inspect the registered tag set and apply materially
useful tags when they create or refine a work item, registering a missing tag
only when it is a reusable project category.
